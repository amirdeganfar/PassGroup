What happens if my app developer disappears? One of two things. If the code and the accounts are yours — in your name, with copies in your hands — you hand everything to a new developer and pay for weeks of catching up. If they're not, you rebuild from zero. Ownership decides which, and ownership belongs in the contract, not the handshake.

What happens if your app developer disappears, step by step

Work this checklist in order:

  • Gather what you hold: contract, invoices, repository invites, store logins, hosting and domain accounts
  • Check the store accounts first — if the app is live and the account is yours, users are safe while you sort the rest
  • Check who owns the code: the contract should name you. If it's silent, default rules apply — IP Australia's guide to who owns IP explains the basics
  • Have a new developer assess the code before promising anything — some codebases are worth continuing, some aren't

Handover or rebuild: the two outcomes

If you own the code and the accounts, a new developer audits, gets access and continues — typically a few thousand dollars plus a few weeks, not a second build. If you don't, you're funding version two from nothing. Your choice of builder prices that continuity risk in: see the cost of a freelance app developer versus the cost of an agency build.

Make it impossible next time

Do

  • Put IP ownership in the contract — yours, in writing, before work starts
  • Register every account with your email and your card
  • Keep the code in a repository you control, backed up weekly
  • Pay against milestones that deliver working software

Don't

  • Let the only copy live on the developer's machine
  • Pay large sums up front for work you haven't seen
  • Wait months when communication goes quiet — set a two-week limit

None of this needs a technical background — one afternoon and a contract that says who owns what. Every good developer expects both.

What happens if my app developer disappears with the code?

If the code was never in a repository you control and the contract doesn't assign ownership, you may have to rebuild. Talk to a lawyer about the contract first — prevention beats litigation on cost.
